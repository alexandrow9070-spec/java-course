# Программа упаковки посылок в кузовы грузовиков

Программа для оптимальной упаковки посылок разного размера и формы в кузовы грузовиков с учетом правил размещения.

## Описание

Программа принимает на вход файл с описанием посылок и размещает их в кузовах грузовиков размером 6x6, соблюдая следующие правила:

- Посылки нельзя вращать
- Посылки не могут висеть в воздухе
- У посылки должна быть опора больше половины её основания
- Каждый кузов имеет размер 6x6

## Использование

Проект собирается и запускается через Gradle.

### Сборка

Находясь в корне проекта:

```bash
gradle build
```

### Запуск основной программы погрузки

Главный класс: `ru.hofftech.omni.shipping.ShippingApp`.

Общий вид команды:

```bash
gradle run --args="<путь_к_файлу> <ширина_кузова> <высота_кузова> <алгоритм> <количество_машин> [json_файл_результата]"
```

Параметры:
- **`<путь_к_файлу>`** – путь к файлу с посылками
- **`<ширина_кузова>`** – ширина кузова (например, `6`)
- **`<высота_кузова>`** – высота кузова (например, `6`)
- **`<алгоритм>`** – имя алгоритма упаковки:
  - `simple` – простой алгоритм (одна посылка — одна машина)
  - `optimized` – оптимизированный алгоритм (пытается разместить несколько посылок в один кузов)
  - `even` – равномерная погрузка по машинам
  - `dense` – максимально плотная погрузка
- **`<количество_машин>`** – максимальное доступное количество грузовиков; при невозможности погрузить все посылки в это число машин выбрасывается ошибка
- **`[json_файл_результата]`** – необязательный путь к JSON-файлу, куда будет сохранён результат погрузки (структура кузовов и посылок)

### Пример запуска погрузки

```bash
gradle run --args="test-input.txt 6 6 dense 10 result.json"
```

В этом примере:
- входной файл — `test-input.txt`
- размер кузова — `6x6`
- алгоритм — `dense` (максимально плотная погрузка)
- доступно 10 машин
- результат дополнительно сохраняется в `result.json`

### Запуск обратной функции (JSON → файл посылок)

Для обратного преобразования (JSON с результатом погрузки → текстовый файл посылок в формате `PackageLoader`) используется класс `JsonToPackagesApp` и отдельная Gradle-задача.

Общий вид команды:

```bash
gradle runJsonToPackages --args="<json_вход> <файл_посылок_выход>"
```

Параметры:
- **`<json_вход>`** – путь к JSON-файлу, сохранённому после погрузки
- **`<файл_посылок_выход>`** – путь к создаваемому текстовому файлу с посылками

Пример:

```bash
gradle runJsonToPackages --args="result.json packages-from-json.txt"
```

После выполнения команда создаст `packages-from-json.txt`, который можно снова передать в `ShippingApp` (или загрузить через `PackageLoader.loadPackages`).

### Формат входного файла

Посылки разделяются пустыми строками. Каждая посылка описывается строками, где символы обозначают содержимое посылки.

Пример (`test-input.txt`):
```
999
999
999

666
666

55555

1

1

333
```

## Алгоритмы упаковки

### Простой алгоритм (SimplePackingAlgorithm)
Каждая посылка размещается в отдельном кузове. Посылка размещается в нижнем левом углу кузова. Требует, чтобы количество машин было не меньше количества посылок.

### Оптимизированный алгоритм (OptimizedPackingAlgorithm)
Пытается разместить несколько посылок в один кузов, перебирая все посылки и размещая их по возможности до исчерпания доступных машин.

### Равномерная погрузка (EvenDistributionPackingAlgorithm)
Размещает посылки равномерно по доступным машинам (round-robin), стараясь распределить нагрузку по кузовам.

### Максимально плотная погрузка (DensePackingAlgorithm)
Сначала сортирует посылки по убыванию площади, затем жадно укладывает их в уже созданные кузова, создавая новые только при необходимости, чтобы минимизировать число используемых машин.

## Валидация

Программа проверяет:
- Размеры посылок (не должны превышать размер кузова)
- Корректность формата входных данных
- Соответствие размеров и формы посылок

## Логирование

Программа использует SLF4J и Logback для подробного логирования процесса упаковки. Конфигурацию логирования можно изменить в файле `logback.xml` (если он добавлен в проект) или в коде, а основной логгер настраивается в классе `[ShippingApp.java](src/main/java/ru/hofftech/omni/shipping/ShippingApp.java)`.
